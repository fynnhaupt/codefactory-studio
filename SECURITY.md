# Security Policy

## Supported Version

Only the latest version of **CodeFactory Studio** is supported at a given time. If
you find a security issue with an older version, please try updating to the
latest version first.

If for some reason you can't update to the latest version, please let us know
your reasons so that we can have a better understanding of your situation.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them using [Private vulnerability reporting](https://github.com/fynnhaupt/codefactory-studio/security/advisories/new).

We will try to acknowledge receipt of your vulnerability report within 48 hours and provide regular updates as we investigate.

## Preferred Languages

We prefer all communications to be in English.
